# 枫桥智盾 - 干部技能赛参赛准备计划

> 完整计划文档请参考原始附件。本文档为项目参考副本。

## 一、评审标准映射分析

### 1. 技术匹配度（30分）- 红线项

| 评分要点 | 项目对应策略 | 风险点 |
|---------|------------|-------|
| 基于国产智能体平台开发 | 明确使用**钉钉·悟空智能体**作为核心开发平台，接入DeepSeek-v4-pro国产大模型 | 需确保所有API调用均为国内备案服务 |
| 本地化部署 | 部署于政务专网/内网/本地服务器，数据不出域 | 需在设计文档中明确部署架构图 |
| 数据不出域 | 所有数据处理在本地完成，不依赖境外云服务 | 需在技术方案中说明数据流转边界 |
| 算法可审计、内容可溯源 | 保留完整的提示词版本、模型调用日志、决策链路记录 | 需建立日志留存机制 |
| **红线：境外未备案API** | 严格审查所有第三方接口，仅使用国内备案服务 | 一旦触碰直接取消资格 |
| **红线：第三方代写代码** | 全程自主开发，保留完整commit记录和开发日志 | 现场答辩需能阐述每个模块的实现细节 |

### 2. 履职有效性（40分）- 核心得分项

| 评分要点 | 量化指标 |
|---------|---------|
| 痛点命中精准 | 五大痛点均有对应功能模块解决 |
| 明显减负增效 | 去重效率提升97%、报告生成减少94%、台账填报减少50% |
| 逻辑闭环可验证 | "多源汇聚→智能去重→分类分析→预警研判"完整闭环 |
| 有量化对比 | 建立使用前后对比数据 |

### 3. 自主完成度（20分）- 证据链建设

- Git版本管理：每日至少3-5次提交
- 开发日志：每日记录工作内容、问题、解决方案
- 技术细节文档：提示词设计、调试过程、踩坑复盘
- 答辩准备：架构图、数据流图、技术选型理由

### 4. 推广可行性（10分）

- 基于钉钉生态，跨单位复用成本低
- 模块化设计便于裁剪
- 基于智能体平台，可持续迭代

### 5. 加分项（+5分）

- 争取在1-2个街道/乡镇试点运行
- 收集试点单位书面评价
