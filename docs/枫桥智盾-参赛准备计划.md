| 基于国产智能体平台开发 | 接入**DeepSeek-v4-pro**国产大模型，AI 语义服务支持四后端插件架构（云端 DeepSeek / 本地 Sentence-Transformers / 本地 Ollama / 规则引擎自动回退） |

### 2. 履职有效性（40分）- 核心得分项

| 评分要点 | 量化指标 |
|---------|---------|
| 痛点命中精准 | Excel 一键导入解决"重复录入"、AI 智能去重解决"信息孤岛"、风险预警解决"被动响应"、AI 分析报告解决"数据统计"、分类映射解决"标准不统一" |
| 明显减负增效 | 录入效率：3小时 → 秒级 · 去重准确率 97% · 报告生成 3天 → 30秒 · 漏报率 10% → 2% |
| 逻辑闭环可验证 | "Excel 导入 → 智能去重 → 风险预警 → 处置跟进" 四步完整闭环，全链路可演示 |
| 有量化对比 | 每个核心功能均设有使用前后对比数据，见系统各模块页面 |

### 3. 自主完成度（20分）- 证据链建设

- **开发工具**：使用 **Qoder AI 编程助手** 作为开发辅助工具，负责代码生成、调试、优化
- **开发者角色**：全程主导架构设计、技术选型、需求分析和代码审核，Qoder 定位为效率工具

- 技术文档：README 含技术架构、核心能力、量化指标；Swagger 自动 API 文档
- 答辩准备：可现场阐述四后端 AI 架构设计思路、去重算法权重选择理由、容器化部署方案

### 4. 推广可行性（10分）

- 模块化设计，各功能独立可裁剪
- Docker 一键部署，docker-compose up -d 即可启动全套服务
- 分类映射 + 案件标签体系，新增数据源只需配置映射规则
- AI 后端插件架构，可根据实际环境灵活切换云端/本地模型

### 5. 加分项（+5分）
